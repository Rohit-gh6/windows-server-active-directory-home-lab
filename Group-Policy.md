
# Group Policy Management (GPO)

## Objective
Understand and implement centralized configuration and security management using Group Policy in an Active Directory domain.

## Implementation
- Explored Group Policy Management Console (GPMC).
- Created and configured Group Policy Objects.
- Linked GPOs to appropriate domain or Organizational Units.
- Explored password and account-related policies.
- Practised configuring and understanding policy settings.
- Studied how Group Policy inheritance and precedence work.
- Verified policy application on domain-joined clients.

## Validation Commands

```cmd
gpupdate /force
gpresult /r
gpresult /h C:\gpresult.html
```

## Key Concepts
- Group Policy Objects (GPO)
- Group Policy Inheritance
- Security Filtering
- Organizational Units (OUs)
- Computer and User Configuration
- Group Policy Processing
