
# Windows Server Installation & Active Directory Setup

## Objective
Deploy Windows Server in VMware Workstation and configure an Active Directory Domain Services environment.

## Environment
- Virtualization: VMware Workstation
- Operating System: Windows Server
- Server Roles: Active Directory Domain Services (AD DS)
- Infrastructure: Domain Controller

## Implementation Steps

1. Created a virtual machine in VMware Workstation.
2. Installed Windows Server and configured initial server settings.
3. Configured hostname, static IP address and DNS settings.
4. Installed the Active Directory Domain Services role.
5. Promoted the server to a Domain Controller.
6. Created and configured an Active Directory domain.
7. Verified domain functionality and domain controller services.

## Additional AD Administration
- Created and managed domain user accounts.
- Configured password policies.
- Implemented Fine-Grained Password Policies (FGPP).
- Explored all five FSMO roles and practised role transfers.
- Documented Global Catalog functionality.
  
## Validation
Verified domain controller configuration and Active Directory functionality using Windows Server management tools and command-line utilities.
