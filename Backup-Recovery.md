
# Windows Server Backup & Active Directory Recovery

## Objective
Practise Windows Server backup and Active Directory recovery procedures to understand data protection and infrastructure recovery.

## Implementation

### Windows Server Backup
- Installed the Windows Server Backup feature.
- Explored backup configuration and scheduling.
- Practised backing up server data.
- Explored backup destinations and recovery options.

### Active Directory Backup & Recovery
- Practised Active Directory backup procedures.
- Explored System State Backup.
- Studied Active Directory recovery methods.
- Practised restoration procedures in the lab environment.
- Explored authoritative and non-authoritative restoration concepts.

## Key Concepts
- Windows Server Backup
- System State Backup
- Active Directory Database
- Active Directory Recovery
- Domain Controller Recovery

## Validation
Verified backup completion and explored the available recovery procedures within the virtualized lab.
