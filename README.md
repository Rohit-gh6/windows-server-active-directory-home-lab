Windows Server & Active Directory Home Lab
About This Project
This is my personal hands-on Windows Server home lab project, built using VMware Workstation to develop practical skills in Windows Server administration, Active Directory, and DNS management.

Technologies Used
VMware Workstation
Windows Server
Active Directory Domain Services (AD DS)
DNS Server

Completed Tasks
Installed Windows Server.
Installed Windows updates and security patches.
Installed AD DS and DNS Server roles.
Configured static IP addressing.
Created Forward and Reverse Lookup Zones.
Configured Active Directory Site.
Verified FSMO roles using netdom query fsmo.
