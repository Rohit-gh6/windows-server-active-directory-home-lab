
# DNS & DHCP Server Configuration

## Objective
Configure DNS and DHCP services to support domain name resolution and automatic IP address allocation within the lab environment.

## DNS Configuration
- Installed and configured the DNS Server role.
- Explored Forward Lookup Zones.
- Configured domain DNS records.
- Understood A, PTR and SRV records.
- Practised DNS name resolution and troubleshooting.
- Verified DNS functionality using nslookup.

## DHCP Configuration
- Installed the DHCP Server role.
- Created and configured DHCP scopes.
- Defined IP address ranges and subnet settings.
- Configured default gateway and DNS server options.
- Tested automatic IP address allocation on client machines.

## DHCP Failover
- Configured DHCP Failover between DHCP servers.
- Explored failover modes and partner server configuration.
- Tested DHCP service availability and IP allocation.

## Validation Commands

```cmd
ipconfig /all
ipconfig /release
ipconfig /renew
nslookup
dcdiag
```
